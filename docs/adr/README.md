# Architecture decision records

Use `NNNN-kebab-case-title.md`, allocating the next unused four-digit number.
Copy the template content into the new file, then replace all explanatory text.
Every record includes date, status, context, decision, alternatives, consequences
and validation. Status is `Proposed`, `Accepted`, `Superseded` or `Rejected`.

Accept decisions through review by affected module responsibilities. Keep old
accepted records as history; use a new record to supersede them and add links
in both directions. Minor editorial corrections may update an existing record.
Link accepted decisions from architecture/module docs and update the open log.
